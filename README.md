# مِدَاد

منصة عربية RTL لإدارة مجموعة قراءة علمية، مبنية على React/Vite وCloudflare Workers + D1 + R2. الواجهة عربية ومصممة للجوال، والخط العربي مضمّن محليًا داخل الحزمة.

## الموجود في هذا المستودع

- صفحة دخول برقم جوال سعودي وحسابات ينشئها المشرف فقط.
- جلسة عشوائية طويلة الأمد في cookie من نوع `HttpOnly` و`SameSite=Lax`، مع `Secure` على HTTPS، وتحديد محاولات الدخول.
- أدوار مفصولة على الخادم: مشرف رئيسي، مشرف مساعد، وعضو.
- عضوية، حالات إيقاف/استبعاد/إعادة، إجازات بتقويم أم القرى في الواجهة وتواريخ ISO في D1، وسجل تغييرات.
- كتاب PDF خاص في R2، وقراءة بصفحات مرتبة وحفظ استكمال الجلسة في D1. يتحقق الخادم من الزمن الأدنى لكل صفحة ومن إتمام جميع الصفحات، ويمنع التكرار.
- توليد جلسة قراءة مدتها 24 ساعة تلقائيًا، وفترة استكمال متأخر حتى 48 ساعة، بعدها لا تُقبل جلسة الإكمال.
- متابعة الأعضاء وسجل العضو وتقارير يومية/أسبوعية قابلة للطباعة أو الحفظ PDF وسجل عمليات للمشرف الرئيسي.
- حذف نهائي لبيانات العضو متاح للمشرف الرئيسي فقط. حذف حساب المشرف المساعد يوقف دخوله ويحفظ سجلاته الإدارية.

## التشغيل المحلي

يتطلب Node.js حديثًا وnpm.

```sh
npm install
npm run db:local
```

في نافذة طرفية أولى شغّل Worker محليًا:

```sh
npx wrangler dev --ip 0.0.0.0 --port 8787 --var BOOTSTRAP_SECRET:local-bootstrap-only
```

وفي نافذة ثانية:

```sh
npm run dev
```

افتح تطبيق Vite على المنفذ 5173. قاعدة البيانات وR2 محليان في Wrangler؛ لا توجد بيانات مستخدمين مضمّنة في المستودع.

لإنشاء أول مشرف محليًا، أرسل `POST /api/bootstrap` مرة واحدة مع ترويسة `x-midad-request: 1` وجسم JSON يحوي `secret` المطابق للقيمة المحلية، و`name` و`phone` و`password` (10 أحرف على الأقل). لا يقبل endpoint التهيئة إلا إذا كانت قاعدة البيانات خالية. بعد ذلك ينشئ المشرف الرئيسي المساعدين والأعضاء من الواجهة.

## إعداد Cloudflare والنشر

لم يُنشأ مورد Cloudflare أو يُنشر التطبيق في هذه البيئة: `wrangler whoami` أفاد بأن Wrangler غير مسجّل الدخول، كما أن معرّف D1 غير متوفر. يلزم إتمام هذه الخطوات بحسابك بعد ربط Cloudflare/تسجيل الدخول إلى Wrangler:

```sh
npx wrangler login
npx wrangler d1 create midad-db
npx wrangler r2 bucket create midad-private-books
```

انسخ `database_id` الذي يعيده أمر D1 إلى `wrangler.toml` بدل `REPLACE_WITH_D1_DATABASE_ID`. لا تجعل حاوية R2 عامة. ثم:

```sh
npx wrangler d1 migrations apply midad-db --remote
npx wrangler secret put BOOTSTRAP_SECRET
npm run deploy
```

بعد النشر، استخدم `POST https://<worker-domain>/api/bootstrap` مرة واحدة مع الترويسة `x-midad-request: 1`، والسر الذي أدخلته، وبيانات المشرف الرئيسي. لا ترسل سر التهيئة أو رمز الدخول في الدردشة. بعد إنشاء المشرف، أزل سر التهيئة:

```sh
npx wrangler secret delete BOOTSTRAP_SECRET
```

اربط نطاقًا مخصصًا من Cloudflare Dashboard إن رغبت، ثم اختبر تسجيل الدخول ورفع PDF والقراءة على النطاق المنشور. إعداد DNS أو النطاق لا يمكن تنفيذه قبل صلاحية الحساب.

## النسخ الاحتياطي والاستعادة

أضفت حزمة نسخ احتياطي تشمل تصدير D1 (المخطط والبيانات) وتنزيل **كل ملفات PDF** المشار إليها في جدول الكتب من R2، مع manifest وبصمات SHA-256 للتحقق من سلامة الملفات. تُحفظ النسخة افتراضيًا خارج المستودع في `$HOME/midad-backups/<UTC timestamp>` بصلاحيات محلية مقيّدة؛ فهي تتضمن أرقام الجوال وبيانات الأعضاء وhashes رموز الدخول، لذا خزّنها على قرص/وجهة مشفّرة ولا ترفعها إلى Git.

بعد تجهيز دخول Wrangler، أنشئ نسخة قبل الإطلاق أو وفق جدول دوري تديره بيئة التشغيل الآمنة:

```sh
npm run backup -- "$HOME/midad-backups/pre-release"
```

للاستعادة الكاملة، أنشئ قاعدة D1 فارغة جديدة أولًا، ثم شغّل الاستعادة. ترفض الأداة الكتابة فوق قاعدة فيها جداول، وتتحقق من checksums، وتعيد ملفات PDF إلى حاوية R2 الخاصة:

```sh
npx wrangler d1 create midad-db-recovery
npm run restore -- "$HOME/midad-backups/pre-release" midad-db-recovery
```

بعد التحقق من القاعدة والكتاب، حدّث `database_name` و`database_id` في `wrangler.toml` إلى القاعدة المستعادة ثم انشر. هذه العملية لا تستبدل قاعدة الإنتاج تلقائيًا.

للتراجع السريع عن تغييرات D1 في مكانها، يدعم Wrangler Cloudflare D1 Time Travel؛ اعرض نقطة الاستعادة أولًا، ثم نفّذ الاستعادة فقط بعد إيقاف الكتابة ومراجعة الأثر:

```sh
npx wrangler d1 time-travel info midad-db --timestamp="<RFC3339 timestamp>"
npx wrangler d1 time-travel restore midad-db --timestamp="<RFC3339 timestamp>"
```

الاستعادة الزمنية تخص D1؛ استخدم حزمة مِدَاد لاستعادة الملفات أيضًا. تشغيل النسخ على جدول تلقائي يتطلب جدولة الأمر من مشغّل آمن يملك دخول Wrangler ومساحة تخزين مشفّرة، ولم أفعّل جدولة أو موارد مدفوعة في هذا الحساب.

## تسجيل الدخول

اعتمادًا على اختيارك، يستخدم الدخول رقم الجوال ورمز دخول مؤقتًا (8 خانات على الأقل) ينشئه المشرف عند إنشاء الحساب؛ لا يظهر الاسم كعامل تحقق ولا توجد خدمة SMS أو رسوم إرسال. رمز الدخول يُخزّن مجزّأً، وتُحد محاولات الدخول الفاشلة، والجلسة تستمر بأمان بعد إغلاق المتصفح. يوصى بتسليم الرمز للعضو على قناة خاصة وتغييره/إعادة ضبطه عند الحاجة.

## الاختبارات

شغّل `npm test` قبل النشر. ينشئ Worker وD1 وR2 محلية مؤقتة ومعزولة، ثم يختبر إنشاء الأدوار وتسجيل الدخول والجلسات والخروج والتكرار والصلاحيات، ورفع PDF وخصوصيته وتحليله، وتوقيت الصفحات والإكمال المتأخر، والغياب وسجل العضو والإجازة والاستبعاد والإعادة والحذف والتقارير. تُحذف حالة الاختبار المؤقتة عند الانتهاء. يتضمن اختبار واجهة الجوال تحقق RTL ونقاط CSS المتجاوبة؛ لا يتوفر محاكي متصفح/جهاز فعلي في بيئة التنفيذ لاختبار اللمس بصريًا.

## الأوامر

- `npm run build` — يبني واجهة الإنتاج.
- `npm test` — اختبارات تكامل محلية معزولة.
- `npm run backup -- <directory>` — حزمة D1 وملفات PDF خاصة إلى مجلد آمن خارج Git.
- `npm run restore -- <backup-directory> <empty-d1-name>` — استعادة آمنة إلى قاعدة D1 فارغة.
- `npm run db:local` — يطبق migrations على D1 المحلي.
- `npm run deploy` — يبني ثم ينشر Worker وملفات الواجهة.
